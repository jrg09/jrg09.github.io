About

I've spent 12+ years building software for places where it has to keep working after launch.

Large line-of-business systems, document workflows, high-volume processing pipelines, and the APIs that hold them together. I care about the whole path: the data model, the API contract, the screen the person actually uses, and the machine it runs on.

Off the clock I run my own infrastructure — a small fleet of Raspberry Pis and a VPS stitched together with WireGuard, private DNS for the house, services behind Cloudflare tunnels, and a local LLM rig I code against every day. Almost everything below started as something I wanted to exist.

The other half of that habit is offensive: I do ethical hacking and penetration testing work, both on lab targets and against my own applications before they reach production. Knowing how an injection, an upload bypass or a traversal actually lands changes how you write the code in the first place.
